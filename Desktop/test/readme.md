Turbo Dodge
Super simple browser car game. Dodge the traffic, try not to crash. Try to get the highest score.

How to run
Open index.html in a browser. That's it.

Keys
← / A — steer left
→ / D — steer right
↑ / W — go faster
↓ / S — slow down
Tips
On a phone, there are on-screen buttons at the bottom too.
Going faster = more points, but trucks come faster.
Best score saves in your browser so it's still there next time.
No build, no install, just open the HTML file.
